# Reviewer desk

RD-01 option A: four read-only actions for the reviewer. The hosted arena,
hosted join command, public full prediction log/score, chain transaction and
outside-agent recording remain explicitly pending. No wallet is requested.

From the repository root, with Python 3.10+ and the pinned dependencies:

```sh
python3 -m pip install -r near/requirements.txt
(cd near && make rehearsal)
(cd near && make desk)
```

Open the printed loopback URL. `rehearsal` finishes without starting a persistent
server. It extracts the exact executable agent from SNAP.md into a clean
temporary owner folder. The agent uses SnapClient over the existing bounded
pipe transport. The real copied room and engine run with a synthetic rival,
HMAC identities and trusted fixture clock; no model, chain or wallet is used.
Existing fixture helpers are reused without executing their test methods.

The generated `near/.demo/segment.json` is a native fixture archive; it includes
public synthetic prediction requests, never real credentials. The desk checks
that archive anew on every evidence read using the existing native replay and
portable projection. It exposes only forecast percentages, immutable locks,
completed life facts and recorded/replayed hashes. Session/grant/signature
fields are removed from the page's JSON. Fixture percentages are not an outside
agent's model forecast. There is no forecast score claim. Segment zero is the
supported portable projection; later segments remain a separate gate.

Reproduce the native final state hash independently:

```sh
python3 -B near/arena/replay.py near/.demo/segment.json
```

The native seal and portable room seal use different formulas and are labelled
separately. A local replay is not a chain check. No deployment, RPC, archival
transaction, custody, mint, claim or testnet NEAR capability is added here.

`(cd near && make rehearsal DEMO_DIR=/absolute/path)` changes the export directory. To read
it, use `python3 -B near/web/runtime.py --demo-dir /absolute/path`. Without an
archive the desk retains pending states; an invalid archive is unavailable,
never checked. The server binds only 127.0.0.1, checks Host/origin, allows fixed
static paths, and supplies no write route or private owner API.

The local artwork and fonts reuse the member page's existing licensed assets.
The page reproduces the approved RD-01 A composition at 640×800; additional
390/768/1440 captures and source-backed states are generated by the new case.
Browser checks require Node and Playwright 1.64.1 (the pinned dependency in
near/members/package.json). Install there and expose its node_modules via
NODE_PATH if needed. The focused entry is:

```sh
python3 -B near/web/test_desk.py ReviewerDesk.test_four_actions_follow_real_local_agent_forecast_and_checked_replay
```

Use DESK_SHOTS=/absolute/path to retain captures and case-report.json. This one
case drives the copied-room/engine demo and actual browser actions, pending,
checked and corrupted-archive states, unavailable transport, source navigation,
clipboard, reload/return, responsive geometry and read-only/origin boundaries.

Forecast presence is independent of a replay check. A checked empty archive says
there are no forecast rows; a record containing only omitted locks says all
forecasts were omitted. When forecasts exist, the summary counts actual forecast
and omission rows. The valid local replay/hash check remains available in each
case. The focused regression builds these three real engine archives:

```sh
python3 -B near/web/test_desk.py ReviewerDesk.test_checked_replay_keeps_empty_omitted_and_present_forecasts_distinct
```
