Wallet test page

Network: TESTNET (play money). Use a new test account, never your own.

1. Sign in. Each button opens that wallet's own sign-in and asks for the account name. Signing in sends no transaction and moves no money.

2. Add the guest key (testnet only). Sign in on testnet first.

The wallet will ask you to approve: a key that can call only (not set), with an allowance of 0.25 NEAR for gas and no payment. If its screen names any other contract or asks for money, do not approve.

3. Test the key (testnet only). Add the guest key first.
One zero-payment call to the market through the guest key; it shows the transaction hash for the checker.
